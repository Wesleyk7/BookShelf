# 📚 BookShelf

Sistema de gerenciamento de biblioteca desenvolvido para organizar livros, empréstimos e devoluções de forma simples e prática.

O projeto conta com uma interface web com dashboard, gerenciamento de livros e acompanhamento de empréstimos.

---

## 🚀 Funcionalidades

- 📊 Dashboard com informações da biblioteca
- 📚 Visualização e gerenciamento de livros
- 🔎 Pesquisa de livros
- 🏷️ Filtros por gênero e status
- 🔄 Controle de empréstimos e devoluções
- ⏰ Identificação de empréstimos atrasados
- 📈 Exibição de informações atualizadas no painel

---

## 💻 Sobre o projeto

O **BookShelf** foi desenvolvido com o objetivo de aplicar conhecimentos de desenvolvimento web na criação de um sistema para gerenciamento de bibliotecas.

A aplicação possui páginas para visualização dos livros, acompanhamento de empréstimos e um dashboard com informações gerais do sistema.

O frontend se comunica com uma API responsável pelo gerenciamento dos dados da aplicação.
